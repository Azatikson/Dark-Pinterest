# Pet-Project-Dark-Pinterest
DarkPin - это минималистичный аналог Pinterest с тёмной темой, созданный на чистом HTML, CSS и JavaScript. Проект показывает, как можно реализовать ключевые механики визуальной соцсети без серверной части.

## Возможности (v0.1)

- Masonry-сетка пинов (как в Pinterest)
- Добавление пинов по ссылке или загрузкой с устройства
- Лайки и удаление пинов
- Поиск по названиям
- Профиль с вкладками «Пины», «Доски», «Коллажи»
- Выпадающее меню аккаунта
- Тёмная тема (единственная тема)
- Сохранение данных в localStorage
- Иконки интерфейса в стиле Pinterest (логотип, домик, камера, профиль)
