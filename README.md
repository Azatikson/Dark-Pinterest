# DarkPin

Пет-проект, вдохновлённый Pinterest, но с полностью тёмной темой. Показывает, как можно создать визуально привлекательный интерфейс с адаптивной сеткой, локальным хранилищем и интерактивными панелями.

## Возможности

- Тёмная тема
- Masonry-сетка пинов
- Добавление пинов по ссылке или загрузкой с устройства
- Лайки и удаление пинов
- Поиск по названиям
- Профиль с вкладками «Пины», «Доски», «Коллажи»
- Выпадающее меню аккаунта
- Выезжающие панели
- Сайдбар с логотипом, кнопками навигации и создания
- Сохранение данных в localStorage

## Технологии

- HTML5
- CSS3 (переменные, тёмная тема)
- JavaScript (без фреймворков и сборки)
- localStorage для хранения пинов, досок и коллажей

## Запуск

1. Склонируйте репозиторий:
   git clone https://github.com/azatikson/darkpin.git

2. Откройте `html/index.html` через Live Server или в браузере.

Никаких зависимостей, сборки и настройки. Проект работает из коробки.

## Зачем этот проект

Pinterest это визуальный инструмент для вдохновения и коллекционирования идей. Но у него светлый интерфейс, который не всем подходит, особенно вечером и для людей, которые проводят в интерфейсах весь день.

DarkPin это эксперимент: как выглядит привычный сценарий работы с пинами, если полностью перевести его в тёмную тему. Заодно я проверил, можно ли собрать полноценный визуальный продукт без бэкенда и без фреймворков.

## Продуктовые решения

Почему именно такой набор фич и такой интерфейс:

- **Тёмная тема как основа, а не как опция.** Дизайнеры, продакты и разработчики проводят в интерфейсах по 8–10 часов. Тёмная тема снижает нагрузку на глаза и становится стандартом для профессиональных инструментов (Linear, Figma, VS Code). В DarkPin тёмная тема не переключатель, а идентичность продукта
- **Masonry-сетка вместо обычной.** Пины это вертикальные изображения разной высоты. Обычная сетка обрезает картинки или оставляет пустоты. Masonry сохраняет пропорции и делает ленту живой, как у оригинального Pinterest
- **Два способа добавить пин: по ссылке и загрузкой.** Это два разных сценария. По ссылке, когда нашёл что-то в интернете и хочешь сохранить. Загрузкой, когда у тебя есть файл на устройстве. Оба закрывают разные потребности и не мешают друг другу
- **Выезжающие панели для создания.** Форма добавления пина не должна занимать экран постоянно. Панель, которая выезжает по действию, оставляет ленту чистой и не отвлекает
- **Профиль с тремя вкладками.** «Пины», «Доски», «Коллажи» это три разные единицы контента. Вкладки дают быстрый доступ к каждой, не перегружая интерфейс
- **localStorage вместо сервера.** Продукт не требует регистрации и работает у любого, кто скачал репозиторий. Это осознанный выбор: для пет-проекта и личного использования сервер не нужен

## Метрики продукта

Как я оценивал бы успех этого инструмента, если бы развивал его как продукт:

- **Activation.** Доля пользователей, которые добавили хотя бы один пин в первую сессию
- **Retention.** Возвращаются ли пользователи добавлять новые пины через день, неделю
- **Соотношение способов добавления.** Что чаще: по ссылке или загрузкой файла. Это влияет на приоритеты в развитии
- **Использование досок и коллажей.** Если пользователи их не создают, значит, эти разделы избыточны или непонятны
- **Поиск.** Сколько пользователей используют поиск и находят ли то, что искали
