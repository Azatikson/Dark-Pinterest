# DarkPin - тёмный аналог Pinterest

DarkPin - это пет-проект, вдохновлённый Pinterest, но с полностью тёмной темой. Проект показывает, как можно создать визуально привлекательный интерфейс с адаптивной сеткой, локальным хранилищем и интерактивными панелями.

## Возможности

- Тёмная тема 
- Masonry-сетка пинов
- Добавление пинов по ссылке или загрузкой с устройства
- Лайки и удаление пинов
- Поиск по названиям
- Профиль с вкладками «Пины», «Доски», «Коллажи»
- Выпадающее меню аккаунта
- Выезжающие панели.
- Сайдбар с логотипом, кнопками навигации и создания
- Сохранение данных в localStorage

## Технологии

- HTML5
- CSS3 
- JavaScript
  
## Запуск

1. Склонируйте репозиторий
2. Откройте `html/index.html` через Live Server или браузер
